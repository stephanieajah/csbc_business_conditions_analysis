# Business Conditions Survey: analysis and ingestion pipeline

Analysis of an extract from a quarterly survey of Canadian business owners, who are
asked whether they expect employment, sales, profitability and investment to
increase, stay about the same, or decrease over the next three months. The extract
covers Q3 2023, Q4 2023, Q1 2024 and Q2 2024, broken down by geography and industry.

**Headline finding:** businesses expect sales and staffing to hold steady but expect
to make less money, which points to costs rising faster than they can be passed on.
This is a squeeze on profits rather than a downturn, and it is not spread evenly:
agriculture, accommodation and food services, and transportation are hit hardest,
while finance and insurance is the only industry expecting profits to rise.

## How to run

Set up the environment:

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

On Windows, activate with `.venv\Scripts\activate` instead.

For Part 1, open `notebooks/analysis.ipynb` and run all cells. It resolves paths
from the repo structure, so it works whether it is launched from the repo root or
from `notebooks/`.

For Part 2:

    python src/ingest.py
    python src/ingest.py "data/raw/Data CSBC-Q3 2024.csv"

The first rebuilds the combined dataset from everything in `data/raw/`. The second
adds a single new quarterly file to the existing combined dataset.
To run the tests:

    pytest tests/

The tests cover the label normalisation, the schema and category checks, the
chronological quarter ordering, the rescaling against each group's own base, and the
reconstruction of a missing response in a quarter that is no longer the most recent.

## What the data needed before it could be analysed

Four issues were found, each of which would have changed the results if left
unhandled.

**Category labels drift between quarters.** Q2 2024 writes the middle response as
"stay the same" rather than "stay about the same", and renames "Investment" to
"Capital Investment". Nothing errors, and row counts stay identical, so the Q2 rows
simply end up in separate categories from the other three quarters. Both are mapped
back to a single agreed form through a lookup that lists every accepted label.
`.map()` is used rather than `.replace()` so that an unrecognised label returns a
blank and can be counted, instead of passing through unnoticed.

**Zeros are suppression markers, not measurements.** 1,043 values are exactly zero,
and 953 of those are in Nunavut, Northwest Territories and Yukon. One example: Yukon
retail, sales, Q2 2024 reads 0.0 increase, 0.0 stay about the same, 0.8 decrease,
which cannot describe a real population. Too few businesses in those groups
responded for a reliable estimate to be published, so the figure is withheld and
arrives as 0. These rows are flagged rather than deleted, so charts can exclude them
while the exclusion stays visible and reversible.

**A fourth response option is missing from the extract.** The three responses add to
100 for Employment but only about 84 for Investment, 96.5 for Sales and 97.2 for
Profitability. The shortfall is a "not applicable" or "don't know" option that was
dropped, and it is largest for Investment because many businesses do not buy
equipment at all. Every group is therefore rescaled against its own total before
anything is compared, which matches the Business Data Lab's published approach of
removing not applicable responses and reweighting each series separately.

**Seven values are blank, all at the national level in Q2 2024.** Six of the seven
are the "decrease" response for Canada with all industries combined, which is the
headline figure. Because every share is divided by its group total, a blank does not
only lose that value: it shrinks the total and inflates the other two. Q2
profitability "stay about the same" would read as 80% instead of about 55%. The
missing values are reconstructed from each metric's average base in the quarters
where all three responses are present, which is stable to within about one
percentage point. Reconstructed points are drawn as hollow markers and noted in the
chart caption.

## Measure used

Both analyses use the net balance: the percentage expecting an increase minus the
percentage expecting a decrease, calculated against each group's own total. Positive
means optimists outnumber pessimists.

The Business Data Lab publishes a diffusion index of the same data as
`100 x (2 x P_increase + 1 x P_same + 0 x P_decrease)`. Because the three shares sum
to one, that reduces to `100 + (P_increase - P_decrease)`, so the two are the same
statistic on different scales.

The net balance has a known blind spot: it discards the share expecting no change. A
reading of zero could mean 10 up, 80 unchanged, 10 down, or 45 up, 10 unchanged, 45
down. The share expecting no change is therefore reported alongside it. This matters
in Analysis 2, where finance and insurance reads +2.5 with 65% expecting no change,
meaning little is expected to happen, while agriculture reads -41.0 with only 46%
expecting no change, meaning genuine and widespread pessimism.

## Assumptions

- Exact zeros are treated as suppressed estimates rather than true zeros.
- The gap between the three responses and 100 is treated as a single missing response
  option, not as an error.
- The three-way base for a given metric is assumed stable enough across quarters to
  reconstruct a missing response. This is supported by the observed variation of
  about one percentage point, but it is an assumption.
- Where a group total is far below 100, the group is treated as unusable rather than
  rescaled, since rescaling a fragment does not recover the missing respondents.

## What could break in future quarters

**A renamed or new category value.** This already happened twice in this extract. The
pipeline fails with an error naming the unrecognised value rather than continuing,
because a silently dropped category changes what the numbers mean. The handling would
be to add the new label to the lookup after confirming what it refers to.

**A renamed or missing column.** The pipeline checks the required columns on load and
raises immediately, naming the missing column. Without that check, pandas would
return a partially empty frame and the failure would surface much later as a wrong
chart.

**A quarter stops being the most recent one.** This was found by testing rather than
predicted. The reconstruction logic originally patched missing values only in the
newest quarter. When a simulated Q3 2024 file was ingested, Q2 2024 stopped being
newest and its values silently reverted to blank, so a quarter that had displayed
correctly the day before disappeared from the chart. The logic now patches any
quarter with a missing response, using the average base from quarters where all three
are present.

**Filenames.** The pipeline reads the quarter from inside the file and finds files by
scanning the folder, so it does not depend on any naming convention.

## Known limitations

- The reconstruction of the missing Q2 2024 values is an estimate. It agrees closely
  with the surrounding quarters, but it is not observed data.
- Territorial coverage is poor. Most territorial groups are suppressed, so the
  analysis is effectively provincial.
- Analysis 2 covers a single quarter, so it shows the current spread across industries
  rather than whether that spread is widening or narrowing.
- The pipeline repeats the cleaning rules rather than importing them from a shared
  module. For a submission of this size that keeps the script self-contained and
  readable, but in a longer-lived project the rules should live in one place.

Roughly 7 hours across both parts, which is over the 3 to 5 hour guideline. Most of
